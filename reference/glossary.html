Glossary

The words the docs, the course and Claude use for the parts of Cadence. Use them in prompts and review comments. A word joins this sheet once a lesson has taught it.

Places

Word Means In Cadence
browser The program that shows the page and reacts to clicks. The docs say client. The tab at localhost:5173. Its console: F12.
server The program that waits for requests and answers them. A role, not a machine. What npm run dev starts. Its console: the terminal.
database Where the data rests, whether or not anything is running. The file data.db. SQLite, so a file, not a program. Only the server opens it.

The journey

Word Means In Cadence
request A message from the browser to the server. A GET asks for a page; a POST sends a change. Typing an address sends a GET. Pressing Save on the admin page sends a POST.
response The server's answer to a request. Finished HTML for a first page load; data for a fetcher.
form data The named fields a POST carries. intent=create&name=Testing. Read on the server with request.formData().
hydration The browser running the component a second time, over the server's HTML, to make the page respond. Why COMPONENT RAN printed in both consoles in lesson 1.
mutation A change to the data: an insert, an update or a delete. The docs' word; the course says "write". Adding a category. Rating a lesson, once the course has you build it.
revalidation React Router running the page's loader again after an action, so the page's data is fresh. Automatic. The LOADER RAN that followed ACTION RAN in lesson 2.

In a route file

Word Means In Cadence
route table The list of every address the app answers to, each paired with its route file. app/routes.ts. A route file not listed there gives a 404.
route file The file that handles one address. The docs say route module. A file in app/routes/, such as admin.categories.tsx.
loader The route file's function that reads what the page needs. Server only. export async function loader. Its result reaches the component as loaderData.
action The route file's function that receives a change and saves it. Server only. The loader's twin. export async function action. Seventeen route files have one.
component The function that describes what the page looks like. Runs on the server, then in the browser. The export default function in a route file, such as Home.
intent This codebase's habit, not a React Router word: a form field that says which job the action should do. create, update or delete on the admin categories page.
fetcher React Router's tool for sending a change (or fetching data) without leaving the page. useFetcher(), then fetcher.submit(…). The answer arrives in fetcher.data.
effect React's "after the page is drawn, do this". Browser only. useEffect(…). Used to show a toast once a fetcher has answered.
toast The small message that slides into the corner and fades. toast.success(…) and toast.error(…), from the sonner library.

Data

Word Means In Cadence
table, row, column How a database keeps data: a table per kind of thing, a row per thing, a column per fact about it. The categories table has five rows and the columns id, name, slug.
schema The description of every table's shape: its columns, their types, what links to what. app/db/schema.ts, written with Drizzle. Its own lesson is coming.
service A file of functions that talk to the database, so that route files do not have to. Server only. app/services/categoryService.ts and its neighbours.
query One instruction to the database, in SQL or in Drizzle's SQL-shaped TypeScript. db.insert(categories).values({ name, slug }) is INSERT INTO categories ….
db The server's open connection to the database. Exported by app/db/index.ts. If it appears outside a service, something is wrong.
